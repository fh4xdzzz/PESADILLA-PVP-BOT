# bot/

El bot de Discord de PESADILLA PVP **se ejecuta en Sparked Host** y NO forma parte
de este despliegue. Este directorio está reservado para versionar el código del
bot en una fase posterior, una vez definido cómo sincronizarlo con Sparked Host
(despliegue manual, webhook de Sparked o CI propio).

Reglas vigentes:

- No migrar el bot a Vercel ni a ningún servidor serverless.
- No modificar el servidor de Sparked Host sin autorización explícita del propietario.
- No usar el token del bot en la web ni en Supabase con permisos elevados.
